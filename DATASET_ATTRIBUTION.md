Dataset attribution

This project fetches the SMS Spam Collection dataset (5,574 English messages) from the UCI Machine Learning Repository using the `ucimlrepo` package.

Citation:
Almeida, T. & Hidalgo, J. (2011). SMS Spam Collection. UCI Machine Learning Repository.
https://doi.org/10.24432/C5CC84

License: Creative Commons Attribution 4.0 International (CC BY 4.0).

The model is an educational prototype and is not a production fraud-detection system.
